# Ishi Cooks — GitHub Pages Website

## Quick setup

1. Create a new **public GitHub repository**.
2. Upload everything inside this folder, keeping `index.html`, `style.css`, and the `assets` folder together.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will give you a public link such as:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

The site is static, so it does not need a server, database, or paid hosting.
